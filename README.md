## 功能

### 年份特殊页

在主题设置中开启「年份特殊页」后，收藏册会按完成年份分组，并在每一年的开头插入一张手账。年份手账与「年度最爱」是同一叶的正反两面，翻过去才看得到，不会同时摊开。

![年份特殊页：2026](docs/images/year-pages.webp)

- **年份页**：手写年份垫一笔金色干刷笔触，右上角盖一枚红色橡皮章，写着这一年打满的款数；年份下方一行小账，记录这一年的成就数、稀有成就数与游玩小时。
- **徽章邮票**：三枚徽章做成邮票，插在集邮册的透明插袋里，膜的上下两端渐隐。票面印着等级，邮戳是这款游戏的完成日期；鼠标悬停时邮票会从插袋里往外抽一点。
- **年度最爱**：三张电影票，存根上印着名次、游戏名和日期。第 1 名的右上方会盖一枚「FAVORITE OF THE YEAR · No.1」红章，只有第 1 名选了游戏才会出现。
- **盖章动画**：翻到年份页时红章盖下，三个邮戳随后一枚接一枚补上；翻到年度最爱时，第 1 名的红章也会盖一次。换完徽章不会重盖大红章，新贴的邮票会补盖邮戳。系统开启「减少动态效果」时直接显示，不播动画。
- **选择器**：优先列出带徽章的游戏，没有徽章图案的游戏会在右上角标注。每款游戏可选普通 1–5 级或闪亮徽章，也可以直接用封面代替；选择保存在本地。
- 没有完成日期的游戏会归入最前面的「更早」一组，不生成年份页。

### 成就卡包

在 Steam 库中新增一页「成就卡包」，把所有全成就游戏装订成一本可以左右翻阅的收藏册。

卡片记录游戏封面、完成日期、成就数、稀有成就与游玩时长。第一次打开会停在最新收录的一页；右页永远是完整卡面，翻到左页则露出卡背。

点击卡片或滚动滚轮可以翻页，页码、书脊与书签会跟着移动。点击或下拉书签，会快速翻阅到离当前最远的一端（最新页或 No.001 首页）；回来时会记住上次翻到的位置。

### 新卡入册

新完成一款游戏后，第一次进入卡包会看到它从书页中央浮现、翻面，再落进预留的空卡槽。多款新游戏会按完成顺序依次入册。

只有动画完整播完，这张卡才会被记为「已入册」。如果中途离开卡包，或在入册前直接关闭 Steam，下次进入时会重新播放，不会漏掉。

![入册动画：一页四张，新收一张](docs/images/intro-4up.gif)

### 一页一张 / 一页四张

在主题设置中切换每页卡片数量：

- **1 张**：默认，一张大卡，插画和完成信息更醒目。
- **4 张**：2×2 四张小卡，翻页次数更少，卡片等比缩放，版式不变。

![一页一张](docs/images/cardpack-1up.webp)

### 装订方式

- **最新优先**：默认，新卡排在前面，第一次打开停在最新收录的一页。
- **顺序入册**：按入册先后排列，旧卡的位置和编号永远不动，新卡接在最后。

翻页提示会跟着装订方式换边，书签快速翻阅的落点也会对应当前装订方向。

### 扉页统计

扉页头像下方会显示收藏卡、金杯、银杯的合计。不需要的话可以在主题设置中关闭。

### 完满主义者展柜

重新设计 Steam 社区个人资料中的完满主义者展柜：封面统一裁切，成就数改为信息条，右下角加上金色徽章，悬停时卡片会轻微抬升，并高亮展现。

对于锁区、下架或客户端取不到封面的游戏，会根据 appid 重新拼接封面地址，依次尝试 `header_schinese` → `header_tchinese` → `header_japanese` → `header`。全部失效时才显示占位封面。

## 下载

提供三种版本，按自己的情况选一个：

| 版本 | 适合谁 | 文件 |
| --- | --- | --- |
| **主题版** | 已经装好 Millennium，或以后只想更新主题 | `AchievementCollection-v1.1.0.zip` |
| **Windows 懒人包** | 原生 Steam，第一次安装 | `AchievementCollection-Lazy-v1.1.0-Windows.zip` |
| **插件版** | 想继续使用其它主题，或使用原版 Steam | `AchievementCollection-Plugin-v1.1.0-Windows.zip` |

到 [Releases](https://github.com/Kevin0036/steam_achievement_improve/releases/latest) 下载，每个 Release 都附带 `SHA256SUMS.txt`。

> 懒人包内置官方原版 Millennium v3.6.2，不需要再去官方渠道慢速下载。仅支持 64 位 Windows 版 Steam。

> **版本策略**：v1.1.0 是最后一个提供主题版的版本。插件版已经覆盖卡包、年份特殊页与展柜功能；后续版本只发布插件版，后续懒人包也只安装 Millennium 与插件。

### 主题版安装

1. 下载并解压，得到含 `skin.json` 的 `AchievementCollection` 文件夹。
2. 把它放进 `<Steam 安装目录>/millennium/themes/`。放好后，`themes/AchievementCollection/skin.json` 应直接存在。
3. 重启 Steam，在 Millennium 设置 → Themes 中选择「成就收藏册」。
4. 打开 Steam 库，在顶部导航菜单中点击「★ 成就卡包」。

### 懒人包安装

1. 完全退出 Steam。
2. 解压整个压缩包（不要只拖出 `Install.bat`），双击 `Install.bat`。
3. 脚本会自动查找 Steam 目录，必要时请求管理员权限；安装前会校验内置 Millennium 压缩包的 SHA256。
4. 完成后启动 Steam，在 Millennium 设置 → Themes 中选择「成就收藏册」。

安装器不会覆盖已有的 Millennium；检测到已安装时，只会安装或更新主题。卸载时双击 `Uninstall.bat`：默认只删除主题，只有确认 Millennium 是由懒人包装入的，才提供连同核心一起卸载的选项。内置的 Millennium 为官方原版，不会自动更新。

如果杀毒软件或 SmartScreen 拦截安装脚本，请先确认文件来自本仓库的 Release 并核对 SHA256；来源不明时不要绕过拦截。

如果卡包入口没有出现，可在主题设置中打开「成就卡包：允许全屏式入口」，再重启 Steam。

### 插件版安装

1. 确认已安装 Millennium。
2. 把 `AchievementCollection` 整个文件夹放进 `<Steam 安装目录>/millennium/plugins/`。
3. 重启 Steam，在 Millennium 的插件列表里启用「成就收藏册」。
4. 再重启一次 Steam 界面（或重启 Steam），库顶部的 Library 菜单里会出现「★ 成就卡包」。

插件版自带成就卡包、年份特殊页与展柜美化，不包含 SpaceTheme 的外观；字体、配色、侧栏等会跟随你当前使用的主题。如果同时启用了主题版，插件会自动让位，避免重复注入。

## 设置

主题设置中的 **Library → 成就卡包**：

| 选项 | 默认 | 说明 |
| --- | --- | --- |
| 单页卡片数量 | 1 | 可选 1 或 4。修改后重新进入卡包生效。 |
| 卡册装订方式 | 最新优先 | 可选最新优先或顺序入册。修改后重新进入卡包生效。 |
| 扉页统计 | 开启 | 扉页头像下方的收藏卡 / 金杯 / 银杯合计。 |
| 年份特殊页 | 关闭 | 按完成年份分组，每年插入一张正反手账：正面年份徽章邮票，背面年度最爱。修改后重新进入卡包生效。 |
| 成就卡包：读取完成日期 | 开启 | 用最后一个成就的解锁时间作为完成日期。按需读取、按 appid 去重，结果缓存 30 天。 |
| 成就卡包：允许全屏式入口 | 关闭 | 主入口失效时，用整页替换库外壳的方式打开卡包。 |

插件版可以在卡册页右上角的「设置」按钮或 Millennium 侧栏的「成就收藏册」面板里调整同样的选项。

## 说明

- 主题版需要 Steam 客户端与 Millennium；懒人包已内置 Millennium。主题本身基于 SpaceTheme，库、商店、社区等页面的整体外观也会随之变化。
- 插件版不依赖成就收藏册主题，兼容其它主题与原版 Steam；更新时从 Releases 下载覆盖插件目录，设置和卡册缓存不会被覆盖。
- 成就卡包读取 Steam 客户端已有的成就与库数据；首次使用会把当前的全成就游戏作为基准，不会播放旧卡的入册动画。
- 新装的 Steam 还没有成就进度缓存时，卡包会请 Steam 建立一次缓存，可能需要等待几秒。
- 游戏新增成就、从「全成就」变回「未完成」后再次打满，会重新作为新收录入册。
- 展柜封面与年份页徽章依赖对应游戏存在可用的客户端资源；取不到时会显示占位图或「无徽章」标记。
