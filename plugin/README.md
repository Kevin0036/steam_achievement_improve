# 成就收藏册 · 插件版

把「成就卡包」、年份特殊页和「完满主义者展柜美化」装进 Millennium 插件：不需要安装成就收藏册主题，
也不改动任何现有主题，原版 Steam、SpaceTheme 或其它主题下都能用。

## 安装

1. 确认已安装 Millennium（https://github.com/SteamClientHomebrew/Millennium）。
2. 把 `AchievementCollection` 整个文件夹放进：
   `Steam安装目录/millennium/plugins/`
3. 重启 Steam，在 Millennium 的插件列表里启用「成就收藏册」。
4. 重启一次 Steam 界面（或重启 Steam），库顶部的 Library 菜单里会出现「★ 成就卡包」。

## 设置与更新

- 卡册页右上角的「设置」按钮，或 Millennium 侧栏里的「成就收藏册」，都可以打开插件面板。
- 面板里可以调整单页卡片数量、装订方式、扉页统计、册子风格、年份特殊页、完成日期读取与手动日期清除。
- 进入卡包时会自动检查 GitHub 上的新版本。发现更新后可以一键下载安装，完整重启 Steam 后生效；面板的「版本与发布」里也可以手动检查或打开发布页。
- 更新只替换插件文件，设置与卡册缓存不会被覆盖。
